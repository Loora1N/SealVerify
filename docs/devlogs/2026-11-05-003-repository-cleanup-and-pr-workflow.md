## 关键决策

- 删除前核对旧仓库只有已备份的 `main` 分支，没有标签、Issue、PR、Release、Fork、Wiki、Pages 或 Discussions。
- 从本地 bundle 实际恢复一个裸仓库，并验证 Git 对象完整性及分支头一致，保留恢复材料。
- API 删除被 GitHub 以 HTTP 403 拒绝后，改由已登录浏览器执行；GitHub 要求身份复核，由用户本人完成验证。
- 当前开发连接可能与维护者使用同一 GitHub 账号，因此采用审阅后手动合并，不要求本人批准自己的 PR。
- 协作流程本身也使用 PR 交付；不自动合并，不修改 `main`，不将文档约定描述为已启用的服务器端分支保护。
