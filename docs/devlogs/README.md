# 开发日志

每次完成开发任务后新增一篇日志，覆盖功能、修复、重构、文档和打包任务。日志用于追踪需求变化、实际实现及验证结果；它不是程序运行日志。

## 使用规则

1. 复制 [TEMPLATE.md](TEMPLATE.md)，命名为 `YYYY-MM-DD-NNN-short-topic.md`。
2. 日期采用 `Asia/Shanghai`，同日编号从 `001` 递增；主题使用简短英文和连字符。
3. 填写真实发生的改动、检查命令、结果与限制，删除不适用的模板提示。
4. 更新下方索引，最新任务排在最前面。中断或部分完成的任务应如实标记。
5. 同一任务的验收补充更新原日志；后续独立任务新建日志，不覆盖历史记录。
6. 需要提交时，将日志与相关改动一起提交。可记录提交主题，不要求写入自身提交哈希。

开发者或开发助手在完成任务时维护日志；目录本身不会自动监听任务或生成日志。本地工作指令和提示词不随仓库分发，公开日志只保留工程变更与验证事实。
